# Design Document: Sector Alpha Hunter (MVP)

> 版本: v0.2.1
> 
> 
> **状态**: Draft
> 
> **目标**: 构建一套基于Python的A股板块轮动监控工具，自动筛选龙头与补涨标的。
> 

## 1. 项目概述 (Overview)

本系统旨在辅助量化交易员或短线游资快速定位当日A股市场的核心热点。通过自动化抓取板块及个股数据，量化“龙头”与“补涨”的筛选标准，替代人工盯盘，提高决策效率。

**核心价值**:

- **可视化交互**: 通过 Streamlit 提供Web端看板，支持盘中实时刷新。
- **信号明确**: 结合“量比”与“市值”因子，通过 `🔴` 高亮标记高潜力的补涨标的。
- **客观**: 消除情绪干扰，严格执行市值与涨跌幅的剪刀差逻辑。

## 2. 技术栈选型 (Tech Stack)

为避免过度设计，MVP版本采用轻量级架构：

- **编程语言**: Python 3.9+
- **数据源**: `AkShare` (主要调用 **东方财富 Eastmoney** 实时板块接口，因其概念分类最符合游资生态)
- **数据处理**: `Pandas` (核心计算引擎)
- **前端UI**: `Streamlit` (快速构建交互式数据看板)
- **输出格式**: Web 页面展示 + CSV 文件下载

## 4. 核心功能逻辑 (Core Logic)

### 4.1 全市场板块扫描 (Sector Scan)

- **数据接口**: 东方财富**概念板块** (Concept Board) 实时行情。
- **处理**:
    1. 按 `涨跌幅` 降序排列。
    2. UI 提供滑块或输入框，让用户动态选择 Top N (如 Top 3 或 Top 5)。
- **输出**: 热门板块列表及板块涨跌幅。

### 4.2 成分股筛选 (Stock Screening)

针对每一个热点板块，拉取其全部成分股数据，并计算以下列表：

### A. 龙头判定逻辑 (The Dragon)

- **定义**: 资金攻击最猛烈、市场合力最强的标的。
- **筛选条件**:
    1. `涨跌幅` >= 9.0% (涨停或准涨停)。
    2. `上市状态` != 'ST' (剔除风险警示股)。
- **排序**: 按 `总市值` 降序 (大市值涨停代表板块强度)。

### B. 补涨挖掘逻辑 (The Catch-up)

- **定义**: 板块大涨但个股尚未起爆，具备低市值弹性的标的。
- **基础筛选 (Base Filter)**:
    1. `涨跌幅`: 0% 到 4% (确保未大涨)。
    2. `总市值`: < 100亿 (小票弹性大，参数可调)。
    3. `换手率`: > 3% (剔除流动性枯竭的死股)。

### 4.3 核心信号生成 (Signal Generator) - *Updated*

在“基础补涨池”中，进一步通过以下逻辑打标，寻找**即时买入点**：

**逻辑**: `IF (板块涨幅 > 2.5%) AND (个股量比 > 1.5)`

- **板块强度校验**: 只有板块整体强势，补涨逻辑才成立。
- **资金异动校验**: `量比 > 1.5` 代表今日资金显著流入，非“跟风”而是“有主动性”。

**结果**: 满足上述条件的个股，在 UI 的 `Signal` 列中标记为 `🔴` (强烈关注) 或 `⚡` (异动)。

## 5. 数据结构设计 (Data Schema)

系统内部统一使用 Pandas DataFrame 进行流转，新增 `volume_ratio` 和 `signal` 字段：

| **字段名 (En)** | **字段名 (Cn)** | **类型** | **备注** |
| `symbol` | 股票代码 | str | e.g., "000001" |
| `name` | 股票名称 | str |  |
| `price` | 最新价 | float |  |
| `pct_chg` | 涨跌幅 | float | 单位 % |
| `market_cap` | 总市值 | float | 单位 亿 |
| `turnover` | 换手率 | float | 单位 % |
| `volume_ratio` | **量比** | float | **关键因子** |
| `signal` | **信号** | str | "🔴" or "" |

## 6. UI 页面结构设计 (Streamlit Layout)

前端页面将分为侧边栏和主区域 (UI 界面采用全中文显示)：

- **Sidebar (侧边栏)**:
    - **参数设置**:
        - “选择扫描板块数 (Top N)” (Slider: 1-10)
        - “补涨市值上限” (Input: 100亿)
        - “量比阈值 (Volume Ratio)” (Input: 1.5)
        - “刷新数据” (Button)
- **Main Area (主区域)**:
    - **概览**: 显示当前最强的 Top N 板块名称及涨幅。
    - **Tab 页**: 为每个热门板块生成一个 Tab。
        - Tab 1: $$低空经济 +4.5%$$
            - **Section 1: 龙头股 (Dragons)** -> Table (高亮涨停股)
            - **Section 2: 补涨挖掘 (Laggards)** -> **交互式 Table**
                - **默认排序**: 优先显示 `Signal` 为 `🔴` 的行，其次按市值升序。
                - **样式**: `Signal` 列使用醒目的颜色标记。
                - **列包含**: 信号 | 代码 | 名称 | 现价 | 涨幅 | 量比 | 市值 | 换手
            - **Download**: "下载该板块数据 (CSV)" 按钮

## 7. 迭代计划 (Roadmap)

- **v0.1.0 (Current)**: 实现包含“量比”因子的筛选逻辑，Streamlit 基础看板，CSV 导出。
- **v0.2.0**: 增加“最早封板时间”以区分龙一龙二；优化多线程数据抓取速度。
- **v0.3.0**: 对接即时消息推送 (飞书/钉钉)。
